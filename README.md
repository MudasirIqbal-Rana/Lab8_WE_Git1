# Lab8_WE_Git1

Web Engineering Lab 8 – Responsive E-Commerce Product Gallery

## About
A product gallery page built with CSS Grid. The layout adjusts to any screen
width automatically, with no media queries.

## Key CSS
```css
grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
```
- `minmax(250px, 1fr)`: every card is at least 250px wide.
- `auto-fit`: fits as many columns as the screen allows.

## Features
- Responsive grid (8 product cards)
- Hover animations: card lift, icon zoom/tilt, button colour change
